# Risk Register

| Risk | Impact | Mitigation |
|---|---:|---|
| Too many features | High | Freeze flagship systems and phase gates |
| LLM API failure | High | Cached demo mode and local fallback |
| Slow multi-agent flow | High | CARE adaptive routing and streaming UI |
| Random/unreliable scores | High | Evidence-only scoring and versioned rules |
| GraphRAG complexity | Medium | Start with small curated skill graph |
| Resume parsing errors | Medium | Structured validation and manual correction UI |
| Voice transcription failure | Medium | Text fallback and preloaded sample audio |
| Weak research claims | High | Baselines, ablations, held-out evaluation |
| Ethical concerns | High | No lie detection, hiring prediction, or emotion claims |
| Demo internet loss | High | Local seed data, cached outputs, backup video |
| UI over-animation | Medium | Motion only for state changes and reasoning paths |
| Team/time constraints | High | Phase exit criteria and prototype-only secondary dashboards |
