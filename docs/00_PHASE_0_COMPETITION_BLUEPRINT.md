# Phase 0 — Competition Blueprint

## 1. Objective

Build the most memorable and technically defensible project in the college internship competition by combining product quality, AI depth, research validation, responsible AI, and an excellent live demo.

## 2. Frozen Product Identity

**Product:** CareerPilot AI  
**Platform:** Career OS  
**Research Core:** CARE Engine  
**Category:** Evidence-grounded adaptive agentic career intelligence platform

### One-line pitch

CareerPilot AI is a Career Operating System that maintains a persistent Career Twin, diagnoses root causes through GraphRAG, dynamically selects AI reasoning pathways using confidence-aware routing, and continuously improves the student's career readiness through measurable interventions.

## 3. Problem Statement

Students currently use disconnected tools for resume review, interview practice, aptitude tests, technical preparation, and learning resources. These systems usually lack:

- Persistent memory across activities
- Root-cause analysis of weaknesses
- Evidence-backed scoring
- Adaptive intervention planning
- Confidence-aware AI behavior
- Continuous reassessment
- Transparent decision traces

## 4. Core Research Question

Can a confidence-aware adaptive agent architecture provide more reliable and efficient personalized career guidance than fixed single-agent or fixed multi-agent systems?

## 5. Flagship Innovations

1. Persistent AI Career Twin
2. CARE adaptive routing engine
3. Career Knowledge Graph and GraphRAG
4. Autonomous improvement loop
5. Career Experiment Lab
6. Evidence-based Interview Arena
7. AI Trust Center
8. Research Benchmark Lab

## 6. Definition of “Winning”

The project must demonstrate all five dimensions:

| Dimension | Evidence required |
|---|---|
| Innovation | Career Twin, CARE, GraphRAG, Experiment Lab |
| Technical depth | Working architecture, databases, agents, APIs, security |
| Real-world value | A student measurably improves through the system |
| Research quality | Baselines, ablations, metrics, failure analysis |
| Presentation quality | One flawless, connected demo journey |

## 7. Non-negotiable Rules

- Every score is evidence-backed.
- Every recommendation connects to a diagnosed weakness.
- Every weakness maps to a root cause where possible.
- Every AI action stores confidence and provenance.
- Every major module updates or consumes Career Twin state.
- No feature may exist only as a disconnected page.
- The live demo must work with cached fallback data.
