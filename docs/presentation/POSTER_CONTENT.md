# Poster Content

Layout guidance and text blocks for a physical/digital poster.

## Header
**CareerPilot AI — The Career Operating System**
*Your Career. Continuously Evolving.*

## Hero visual
Animated (or static-rendered) Career Twin orb, matching the Competition
Mode opening slide's gradient sphere motif — the same visual identity used
throughout the product, not a stock illustration.

## Panel 1 — The Problem
Disconnected tools. No memory. No explanation. No evidence.

## Panel 2 — Career Twin
Evidence-backed, six-component readiness model. Never a fabricated score.
Small-sample safeguard prevents one session from reading as an
established skill level.

## Panel 3 — GraphRAG
Real structured knowledge graph. Root cause, not a guess.
`Student → failed question → concept → missing prerequisite → role requirement`

## Panel 4 — CARE
6 confidence-aware routes. One agent when that's enough. A council when
it's not. Human review when confidence stays low.

## Panel 5 — Interview Arena
Voice or typed. 5 specialist agents. Resume-claim evidence checking —
respectful, never an accusation.

## Panel 6 — Experiment Lab
Deterministic, versioned simulation. "Personalized scenario estimate —
not a guaranteed outcome or hiring prediction."

## Panel 7 — Research Proof
Real experiments, run on demand. CARE vs. fixed routing. Graph vs. vector
retrieval. Calibration from real data.

## Panel 8 — Responsible AI
No hiring probability. No lie detection. No public ranking. Full
student-controlled data export and deletion.
