# Seven-Minute Standard Demo

The default competition-slot length. Structure matches the brief's
required flow: Problem → Career Twin → Root cause → CARE → Mission →
Interview Replay → Experiment Lab → Research → Responsible AI → Closing.

| Time | Segment | Screen | Talking point |
|---|---|---|---|
| 0:00-0:30 | Problem | `/competition` Opening | Disconnected tools, no memory, no explanation, no evidence |
| 0:30-1:15 | Career Twin | `/career-twin` (live) | Six components, each with evidence count + confidence, `insufficient_evidence` shown honestly where real |
| 1:15-2:00 | Root cause | `/trust-center` → a `root_cause_analysis` execution | Graph traversal, not a guess; Neo4j vs. relational-fallback badge |
| 2:00-2:30 | CARE | Same Trust Center execution, or a second one | Route, routing factors, agents invoked, confidence, cost, latency all real and stored |
| 2:30-3:00 | Mission | `/dashboard` mission card | Root-cause-aware mission with concrete tasks and a recommended resource |
| 3:00-4:15 | Interview + Replay | `/interview` → answer → `/interview/[id]/replay` | Live CARE-routed evaluation, dimension scores, evidence check, timeline markers |
| 4:15-5:15 | Experiment Lab | `/experiment-lab` | Run "20h SQL" vs "20h Communication" live, compare side by side, read the disclaimer aloud |
| 5:15-6:00 | Research proof | `/research-lab` | Run Experiment A live; show the real (not pre-baked) agreement-rate chart |
| 6:00-6:30 | Responsible AI | `/responsible-ai` | The "never evaluates" list; model/formula/policy versions |
| 6:30-7:00 | Closing | `/competition` final step | "Your Career. Continuously Evolving." |

Rehearsal note: steps that "run live" (Experiment Lab, Research Lab) take
2-4 seconds against the deterministic provider — safe to do in front of
judges without a delay.
